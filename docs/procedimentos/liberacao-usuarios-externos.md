## Sintoma

Necessidade de permitir que usuários externos (não vinculados ao IFRN) acessem laboratórios para cursos, oficinas ou atividades pontuais.

## Contexto

Usuários externos precisam de credenciais de acesso para utilizar laboratórios do IFRN. O procedimento varia conforme o tipo de atividade (curso, extensão, empréstimo de espaço).

## Procedimento

### 1. Identificar o tipo de atividade

- **Curso ou minicurso:** atividade com docente responsável e vínculo com Ensino, Pesquisa, Extensão ou Internacionalização.
- **Empréstimo de laboratório:** atividade sem vínculo institucional direto, apenas uso do espaço.

### 2. Para cursos ou minicursos

1. Cadastrar a atividade como minicurso ou atividade de extensão no SUAP.
2. O coordenador do projeto pode cadastrar os participantes diretamente no sistema.
3. Os participantes são tratados como alunos regulares para fins de acesso.
4. Solicitar que os participantes se cadastrem previamente no SUAP como usuários externos.

### 3. Para empréstimo de laboratório

1. Solicitar que os alunos se cadastrem com antecedência via GOV.BR no portal do IFRN.
2. Após o cadastro, solicitar a criação de senha de acesso para uso no dia da atividade.
3. Registrar formalmente a finalidade, período, responsável e laboratório envolvido.

### 4. Documentar a solicitação

- Registrar em sistema de chamados ou processo administrativo:
  - Nome do responsável pela atividade.
  - Período de uso do laboratório.
  - Lista de participantes (nome, documento, instituição de origem).
  - Justificativa para o uso do laboratório.

### 5. Orientar os participantes

- Informar sobre as normas de uso do laboratório.
- Esclarecer sobre responsabilidades em caso de danos ou mau uso.
- Fornecer contato de suporte técnico para o dia da atividade.

## Quando escalar

- Quando houver dúvidas sobre o enquadramento da atividade.
- Quando o número de participantes for muito grande.
- Quando a atividade envolver equipamentos ou softwares específicos.

## Equipe responsável

COTIC do campus, coordenador do projeto e setor responsável pelo laboratório.

## Nível de confiabilidade

Prático.

## Notas adicionais

- Se houver docente envolvido, a atividade deveria ter vínculo com Ensino, Pesquisa, Extensão ou Internacionalização.
- O cadastro prévio evita atrasos no dia da atividade.
- Para atividades recorrentes, considerar a criação de projeto ou curso formal no SUAP.
- Este procedimento pode mudar conforme atualizações do SUAP ou normativos institucionais.
