## Sintoma

Servidores e alunos têm dúvidas sobre quais licenças Microsoft estão disponíveis, como acessar e quais limitações existem (especialmente para Mac).

## Contexto

O IFRN possui licenças educacionais da Microsoft via Azure Education, mas há limitações conhecidas, especialmente para usuários Mac.

## Procedimento

### 1. Licenças disponíveis

#### Para servidores

- **Office 365 A3/A5:** Acesso completo ao Office desktop (Windows).
- **Microsoft 365 Apps:** Aplicativos Office atualizados.
- **Windows 10/11 Education:** Licenças de sistema operacional.
- **Visual Studio Enterprise:** Para desenvolvedores.
- **Azure DevOps Server:** Para gestão de projetos.

#### Para alunos

- **Office 365 A1:** Acesso via web (não inclui desktop).
- **Microsoft 365 Apps para Educação:** Aplicativos gratuitos.
- **Azure for Students:** Créditos e serviços Azure.

### 2. Limitações conhecidas

#### Office para Mac

- **Problema:** Licenças educacionais podem não permitir edição no Mac.
- **Solução possível:** Tentar ativar Office LTSC 2021 (se disponível).
- **Alternativa:** Usar Office via web (office.com).
- **Status:** Contrato atual pode incluir apenas versão web para Mac.

#### Acesso de alunos

- Alguns alunos relatam dificuldade para acessar Office 365.
- Professor deve convidar aluno para equipe/classe.
- Aluno precisa aceitar convite e comprovar vínculo.

### 3. Softwares disponíveis via Azure Education

Baseado no portal Azure Education do IFRN:

#### Sistemas Operacionais

- Windows 10 Education (22H2)
- Windows 11 Education (25H2)
- Windows Server 2019/2022/2025 (Standard e Datacenter)
- Windows 10/11 Language Packs

#### Office e Produtividade

- Access 2016/2021
- Project Professional 2019/2021
- Visio Professional 2016/2019/2021
- SharePoint Server Subscription Edition
- Skype for Business Server 2019

#### Desenvolvimento

- Visual Studio Enterprise 2019/2022/2026
- Visual Studio Community 2019
- Visual Studio Code
- Visual Studio para Mac
- Azure DevOps Server 2022/2025

#### Banco de Dados e Analytics

- SQL Server 2019 (Developer e Standard)
- Machine Learning Server 9.3.0/9.4.7 (Windows, Linux, Hadoop)
- Microsoft R Client 9.4.7
- Datazen Enterprise Server

#### Infraestrutura

- System Center 2022/2025 (DPM, SCOM, SCVMM, etc.)
- Microsoft Endpoint Configuration Manager
- Microsoft Hyper-V Server 2019

### 4. Como acessar

1. Acessar [portal.azure.com](https://portal.azure.com/).
2. Fazer login com conta institucional.
3. Navegar até "Azure Education".
4. Selecionar software desejado.
5. Baixar e instalar conforme instruções.

### 5. Troubleshooting

#### Office no Mac não permite editar

- Verificar tipo de licença (pode ser apenas web).
- Tentar ativar com conta institucional.
- Usar alternativa: Office Online ou LibreOffice.

#### Aluno não consegue acessar

- Professor deve convidar aluno para equipe.
- Aluno aceita convite e comprova vínculo.
- Se persistir, contatar suporte do Canvas/Office 365.

#### Servidor não encontra software na lista

- Verificar se a conta tem permissões adequadas.
- Alguns softwares podem requerer solicitação específica.
- Contatar DINRE para acesso.

## Quando escalar

- Quando houver dúvidas sobre elegibilidade para licenças específicas.
- Quando o acesso for negado sem explicação.
- Quando múltiplos usuários relatarem o mesmo problema.

## Equipe responsável

DINRE (Diretoria de Infraestrutura de Redes e Serviços).
